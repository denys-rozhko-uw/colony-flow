# Ant Picture

Головоломка по принципу Colony Flow. Исходники находятся в этой папке; нужен Godot 4.5.1.

## Запуск

Открыть `project.godot` через `C:\Godot\Godot_v4.5.1-stable_win64.exe` и нажать F5. Из меню выбрать «Продолжить». Для проверки из PowerShell: `./tools/check.ps1`.

В игре есть 20 уровней-заготовок, пять слотов, выбор коробок, движение муравьёв, победа/тупик, пауза, повтор, выбор уровней и сохранение прогресса. Коробка уносит блоки своего цвета; для доступа к глубокой клетке сначала нужно убрать блоки снизу. Число на коробке — сколько блоков она должна доставить. В настройках можно менять громкость, символы цветов и уменьшить движение муравьёв.

Текущая графика состоит из простых цветных клеток и точек-муравьёв, звуки — из собственных синтезированных сигналов. Кампания служит проверке правил и интерфейса; до выпуска ей нужны ручная оценка сложности, развитие форм картинок и окончательная проверка. Готовой Windows-сборки нет: на этом компьютере не обнаружены шаблоны экспорта Godot 4.5.1.

Исходные уровни находятся в `data/levels/`, порядок — в `manifest.json`. Для нового уровня нужны схема из [ARCHITECTURE.md](ARCHITECTURE.md), корректный `solution_order` и успешные `tools/validate_levels.gd` / `tools/verify_solutions.gd`. Уровни 002–020 можно воспроизвести скриптом `python tools/generate_placeholder_levels.py`. Сохранение игры расположено в `user://progress.json`; текущая партия при выходе начинается заново.

Текущий статус и следующие задачи — [TASKS.md](TASKS.md). Игровые правила и формат уровней — [ARCHITECTURE.md](ARCHITECTURE.md).
