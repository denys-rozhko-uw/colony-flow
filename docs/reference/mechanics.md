# Наблюдения о Colony Flow

Проверено 14.10.2026 по [описанию разработчика в Google Play](https://play.google.com/store/apps/details?id=com.abi.colony.flow). Это текстовое описание, а не запись игрового процесса. Чужие изображения, уровни, звуки и название в игру не переносятся.

| Деталь | Наблюдение | Уверенность |
|---|---|---|
| Цветные коробки | После нажатия муравьи уносят блоки соответствующего цвета | Высокая: прямо сказано в описании |
| Пять слотов | Выбранные коробки занимают до пяти слотов, завершённая освобождает слот | Высокая: прямо сказано |
| Порядок запаса | Выбор открывает спрятанные ниже коробки | Высокая: сказано, точная схема блокировок неизвестна |
| Тупик | Пять занятых бесполезных слотов приводят к остановке | Высокая: прямо сказано |
| Цель | Убрать все блоки с картинки; ограничение времени не заявлено | Высокая: прямо сказано |
| Доступность клетки | Точный алгоритм и направление подхода муравья не опубликованы | Неизвестно |
| Число на коробке | Смысл и момент списания по официальному описанию не установлен | Неизвестно |
| Момент разблокировки | Неизвестно, достаточно ли выбора верхней коробки или требуется её завершение | Неизвестно |
| Момент проигрыша | Описание не формализует ситуацию с муравьями уже в пути | Неизвестно |

Для неизвестных деталей в [ARCHITECTURE.md](../../ARCHITECTURE.md) принят исполнимый набор правил `frontier_v1` (A01–A06): доступ снизу по пустому пути, квота равна числу доставок, зависимости снимаются при отправке, проигрыш только после остановки текущих рейсов. При появлении достоверного наблюдения обновить эту таблицу, ADR, тесты и уровни. Пока доступных материалов для уверенной сверки нет; это не блокирует собственную реализацию.
